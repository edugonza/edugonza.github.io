*Process mining on databases: extracting event data from real-life data sources* (2019),
supervised by Hajo Reijers and Wil van der Aalst. It tackles data extraction, event log
building and event data querying in environments where many business processes coexist.
The goal is to help practitioners start a process mining project in an unfamiliar
environment, even when domain knowledge isn't available, and to give them the tools to
query event data and build event logs for more effective analysis. It was published in
the SIKS Dissertation Series (2019-03) and is
[open access](https://research.tue.nl/p/file/document/118750237/20190227_Gonzalez.pdf).
